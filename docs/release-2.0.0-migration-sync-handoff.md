# Carve 2.0.0 필사 이전·iCloud 동기화 — 현재 상태

기준: 2026-09-28 develop 머지 시점. 제품 결정은 [출시 범위](./release-2.0.0-migration-sync-scope.md), 실행 증거(명령 · 수치 · 한계)는 [호환성 시험 계획](./icloud-sync-compatibility-test-plan.md)을 따른다. 09-23~28의 날짜별 인계 로그는 이 문서의 git 이력에 있다.

## 판정

필사 이전·동기화의 필수 관문(업데이트 무유실 · 옛 무계정 필기의 첫 로그인 전송 · 시간차 양방향 동기화 · 실패 시 보존)은 시뮬레이터 · Development CloudKit · Debug 실기기 범위에서 통과했다. 출시 판정은 아래 「남은 관문」의 배포 검증이 끝날 때까지 보류한다.

## 지금 코드가 하는 일

1. **업데이트 보존:** 새 모델로 저장소를 열기 전에 원시 사본(Preservation)을 뜨고, CloudKit 없이 로컬 마이그레이션한다. 사본을 뜨지 못하거나 마이그레이션이 실패하면 연결하지 않는다.
2. **연결 전 소유 판정:** `.private` CloudKit 연결 전에 계정 식별과 저장소 소유를 확인한다. 처음 연결할 때의 근거는 네 가지다 — 처음 저장소가 없던 설치(`firstRunHadNoStore`), 계정 연결 없는 1.3.0 V3 원본(`firstLoginFromUnaccountedV3`), 기존 로그인 저장소(`currentPrivateCloudRecords`: 검증 OS 17 · 18 · 26 · 27, 모든 행 대응, 서버 레코드 조회), 앱 데이터가 없는 연결 저장소(`emptyLinkedStore`).
3. **재실행 판정:** 한 번 근거를 남긴 저장소는 Core Data 가 남긴 CloudKit 계정 식별이 현재 계정과 같으면 재실행 때 다시 증명하지 않고 연결한다. 식별이 다르면 근거가 있어도 보류한다.
4. **보류 중:** 기존 필사는 읽고, 새 필기는 로컬 초안에 쓰며, 동기화 쓰기와 전체 삭제는 막는다. 설정 → iCloud 는 로그인 상태와 연결 상태를 따로 적는다.
5. **로그인 뒤 연결은 재실행으로:** 실행 중에 저장소를 다시 연결하지 않는다(옛 ModelContainer 가 해제되지 않아 실측에서 local-only 로 되돌아갔다). 보류 중 로그인 · 소유가 확인되면 로딩 없이 「연결을 완료하려면 앱을 완전히 종료한 뒤 다시 열어 주세요.」 를 한 번 안내한다.
6. **알려진 제한:** 두 iPad 에서 같은 절을 동시에 고친 경우의 양쪽 보존, 1.3.0 · 2.0.0 혼용 편집의 충돌 해결, C14 분리 · 명시적 가져오기(게이트 코드는 남아 있지만 출시 경로에서 쓰지 않는다).

## 남은 관문

1. **Xcode 27 출시 후보 빌드와 전체 회귀.** Xcode 26.x 로 빌드하면 iOS 27 SwiftData 의 1.0.x 저장소 폴백 분기가 컴파일에서 빠지므로 출시 후보는 Xcode 27 로 만든다. Xcode Cloud 는 09-25 확인 당시 `DevelopBranch` 가 Xcode 26.6 · `FORCE_BUILD_RESET=1`(build number `1` 로 되돌아갈 위험), `MAIN` 이 Xcode 26.3 · TestFlight 단계 없음이었다 — 후보를 돌리기 전에 [workflow 확인 기록](./icloud-sync-compatibility-test-plan.md#xcode-cloud-testflight-build-220의-툴체인-확인-2026-09-25)을 본다.
2. **배포 검증:** 배포 서명 Archive/export, Production CloudKit 스키마 배포(즐겨찾기 `CD_FavoriteVerse` 등 새 레코드 타입 · 필드), TestFlight 후보를 실기기에 업데이트 설치해 보존 · 연결 확인.
3. **미결정 · 미확인:** 이전 빌드나 계정 미확인 상태에서 소유 근거 없이 쓰인 초안을 연결 뒤 저장소에 넣을지, iPadOS 27 의 무계정 V3 metadata profile, 계정 식별이 캐시되기 전 첫 실행이 오프라인인 경우, 저장소에 쓰지 않는 절에서 「지우기」 · 「이전 필사 내용 보기」 가 이유 표시 없이 사라지는 점(`ChapterCanvasMenuAvailability`).
